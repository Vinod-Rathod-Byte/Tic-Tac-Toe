# Tic Tac Toe Game

A simple and interactive Tic Tac Toe game built using HTML, CSS and JavaScript.

## Features

- Two-player gameplay
- Interactive game board
- Win detection
- Draw detection
- Restart game option
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Play

1. Player O starts the game.
2. Players take turns selecting an empty cell.
3. The first player to get three symbols in a row, column or diagonal wins.
4. If all cells are filled without a winner, the game is a draw.
